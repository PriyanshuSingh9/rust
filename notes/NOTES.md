# Teaching Scratchpad and User Preferences

- Schedule allocation:
  - Monday to Thursday: 1 to 2 hours (reading, note-taking, concept verification).
  - Friday to Sunday: 3 to 5 hours (Rustlings drills, milestone project development).
- Instruction requirements:
  - Explain from first principles.
  - Provide worked examples with concrete memory layouts.
  - Treat compiler errors as proofs of program safety rather than arbitrary friction.
  - Strictly zero emojis in all files, documentation, and source code.
  - Update progress.html empirically based on git commits and file modification times.
