# Rust Resources

## Knowledge

- [The Rust Programming Language (TRPL)](https://doc.rust-lang.org/book/)
  Primary source for language fundamentals, ownership model, and standard library mechanics.
- [The Rust Reference](https://doc.rust-lang.org/reference/)
  Formal specification of language grammar, type layouts, and memory model.
- [Francesco Ciulla, The Rust Programming Handbook](https://github.com/FrancescoXX/rust-handbook)
  Practical guide for modern production tooling (Axum, SQLx, Docker, WASM).
- [Jon Gjengset, Rust for Rustaceans](https://nostarch.com/rust-rustaceans)
  Advanced reference for API design, unsafe code invariants, and type-system patterns.
- [Luca Palmieri, Zero To Production In Rust](https://www.zero2prod.com/)
  Architecture guide for production web backends, observability, and database migrations.
- [Mara Bos, Rust Atomics and Locks](https://marabos.nl/atomics/)
  Low-level concurrency, memory ordering, and synchronization primitives.
- [The Rustonomicon](https://doc.rust-lang.org/nomicon/)
  The dark arts of unsafe Rust and undefined behavior boundaries.

## Wisdom (Communities)

- [The Rust Users Forum](https://users.rust-lang.org/)
  Official forum for compiler diagnostic questions and design discussions.
- [r/rust](https://reddit.com/r/rust)
  Community discussions, crate announcements, and design critiques.
- [Tokio Discord](https://discord.gg/tokio)
  Technical discussions on asynchronous runtimes and network architecture.
